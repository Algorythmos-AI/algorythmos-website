# Security policy

This repository holds the public website of Algorythmos Pty Ltd. It is a static
Astro site with a single serverless contact endpoint.

## Reporting a vulnerability

Email **info@algorythmos.com.au** with the subject line `Security report`. Include
the affected URL or file, steps to reproduce, and any proof of concept. Please do
not open a public issue for security findings.

You will receive an acknowledgement within three business days. We ask for a
reasonable disclosure window while a fix is prepared and deployed.

## Scope

- `https://algorythmos.com` and its locale paths (`/au-en`, `/fr-fr`)
- The `/api/contact` endpoint
- This repository's build and CI configuration

Third-party services (hosting, analytics, booking) are governed by their own
programmes.
