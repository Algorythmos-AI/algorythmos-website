## What was broken and what I fixed

### BLOCKER A1 — `ReferenceError: Rocket is not defined` on `/`
- **Location:** [src/pages/home/AdvancedBusinessWebsite.jsx:278](src/pages/home/AdvancedBusinessWebsite.jsx#L278)
- **Cause:** `<Rocket />` and `<Sparkles />` were used in JSX but absent from the `lucide-react` import list. First navigation to home threw a ReferenceError and unmounted the entire home page tree.
- **Fix:** Added `Rocket, Sparkles` to the existing `lucide-react` import.
- **Commit:** `684d509` — *fix(home): import missing Rocket and Sparkles icons*
- **Verified:** Homepage now renders with 0 console errors across all six service cards (Bot, ScanText, BarChart3, Workflow, ShieldCheck, Compass).

### BLOCKER A2 — CI `npm ci` ERESOLVE loop (pre-existing, but blocked verification)
- **Cause:** `@vitest/coverage-v8@^4.1.4` requires `vitest@4.1.4`; project pins `vitest@^3.2.4`. This was introduced in commit `f94f3fc` when coverage was added but snuck past because `npm install` on developer machines permits the conflict while CI's `npm ci` does not.
- **Fix:** Downgraded `@vitest/coverage-v8` to `^3.2.4` and regenerated lockfile.
- **Commit:** `3ba96ba` — *fix(deps): align @vitest/coverage-v8 with vitest 3.x*
- **Verified:** CI `Build Production` now passes (was failing), Vercel preview now deploys successfully (was Error).

2. Temporarily disable preview protection (Settings → Deployment Protection → Vercel Authentication → Off) — not recommended outside of audit runs.
